🛍️ Qianyu Mall API 接口文档

qianyu-mall-service — 共 72 个 API 端点，覆盖 11 个业务模块。C 端 19 个场景 + B 端 12 个场景全链路支持。

✅ MVP 可接入 72 Endpoints 11 Modules 27 Controllers

✅ 分析结论：API 完整度足够支撑 MVP 商城

全链路覆盖：首页 → 商品浏览分类搜索 → 详情 → 购物车 → 下单 → 支付 → 订单管理 → 售后 → 物流 → 评价。B 端包含商家入驻、商品管理、订单处理、财务结算。

  • C 端 19 个场景 — 首页、分类、搜索、详情、购物车、下单、支付、订单、售后、物流、地址、收藏、浏览历史、评价、店铺
  • B 端 12 个场景 — 入驻、仪表盘、店铺管理、商品CRUD、SKU管理、分类品牌管理、订单处理、售后审核、运费模板、库存、财务、评价管理
  • 注意点：优惠券管理 API 未在 mall-service 中暴露；用户登录需接入 qianyu-user-service
